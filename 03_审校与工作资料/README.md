# 审校与工作资料

- `历史工作资料/`：原有审校记录、测试资料、脚本与审计快照；历史文档中的旧路径保留作为记录，不保证可直接点击。
- `HANDOFF.md`：历史交接和当前状态。
- `提取版移出审校注记.jsonl`：从提取稿中分离的审校状态与空白确认说明。
- `PDF原版迁移前校验清单.json`：原始 PDF 的 SHA-256 和大小。
- `答案页临时核查图/`、`OS答案页待核对草稿迁移区/`：临时工作资料。

机械审计：在知识库根目录运行 `python3 03_审校与工作资料/历史工作资料/审计逐页.py`。历史转换脚本保留原样，可能依赖旧目录，使用前需检查路径。
